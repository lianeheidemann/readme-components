## Usage

Use a relative path when the badge is inside the same repository:

```html
<img src="material/my_creations/project-under-construction-gear.svg" alt="Project Under Construction" />
```

Or use the raw GitHub URL when displaying it from another repository:

```html
<img src="https://raw.githubusercontent.com/lianeheidemann/readme-components/main/material/my_creations/project-under-construction-gear.svg" alt="Project Under Construction" />
```
